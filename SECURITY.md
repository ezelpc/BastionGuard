# Security Policy

BastionGuard is a DevSecOps / Secure SDLC laboratory and portfolio project.

## Reporting
Report vulnerabilities privately to the repository owner before opening a public issue. Do not disclose secrets, credentials, personal data, or exploit details that could affect third-party systems.

## Security controls
The project demonstrates SAST, SCA, secret scanning, IaC scanning, container vulnerability scanning, dependency update automation, and hardened container practices.

## Authorized testing
Security tests must be performed only against systems and environments for which you have explicit authorization.
